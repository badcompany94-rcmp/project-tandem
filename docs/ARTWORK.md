# Community artwork

The Project Tandem project header, desktop icon, and application icon use artwork by **POOTERMAN** ([P00TERMAN on GitHub](https://github.com/P00TERMAN)).

- [Artist portfolio on DeviantArt](https://www.deviantart.com/pooterman)
- [Original artwork and offer to use it for this project, issue #11](https://github.com/badcompany94-rcmp/project-tandem/issues/11)
- Original PNG: `distribution/assets/project-tandem.png`
- Windows icon: `distribution/assets/project-tandem.ico`

The original PNG is preserved as supplied. The ICO contains resized copies for Windows icon sizes. Thank you, POOTERMAN, for spending your time creating and sharing this awesome artwork with Project Tandem!

The artist's contribution was offered for this project's icon and header. This acknowledgement does not change the rights in the original game characters or grant a separate artwork license to others.
