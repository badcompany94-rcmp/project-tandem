# Community artwork

The Project Tandem project header features artwork by **POOTERMAN** ([P00TERMAN on GitHub](https://github.com/P00TERMAN)). Thank you for spending your time creating and sharing this awesome artwork with the project!

- [Artist portfolio on DeviantArt](https://www.deviantart.com/pooterman)
- [Original artwork and offer to use it for this project, issue #11](https://github.com/badcompany94-rcmp/project-tandem/issues/11)
- [Original PNG](../distribution/assets/project-tandem.png)
- [Windows icon file](../distribution/assets/project-tandem.ico), containing 16, 24, 32, 48, 64, 128 and 256 pixel sizes

The original PNG is preserved as supplied. The ICO contains resized copies for Windows icon sizes. Public Beta 6 uses this artwork for the application and optional Project Tandem shortcut icons. Previous release downloads are unchanged.

The artist offered this contribution for the project's icon and header. This acknowledgement does not change the rights in the original game characters or grant a separate artwork license to others.
