# Security reports

Please keep private session credentials, account information, player addresses, and exploit details out of public Issues.

If this repository offers **Security → Report a vulnerability**, use that private channel for a sensitive report. If it is unavailable, open an Issue with only a general description and request a private reporting channel before providing sensitive details.

For ordinary bugs, use the bug-report template and provide reviewed diagnostic excerpts. Do not upload the ISO, generated game, the installed `local-data` folder, or EOS configuration.

The beta is intended for play with people you trust. A room code is an invitation, not a substitute for trusted participants. The project's network validation and guest identities do not claim to provide competitive anti-cheat guarantees.
